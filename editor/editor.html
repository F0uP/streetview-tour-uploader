Upload to Google Street View Close

One-time setup, about 5 minutes: Google needs you to register this app as your own free "OAuth client". Work through the steps, each link opens the right page of Google Cloud Console.
  1. 1Create a Google Cloud project
    Sign in with the Google account that should own the photos, give the project any name (e.g. Street View Upload) and click Create. Make sure it is selected in the project picker at the top afterwards.
    Open "New project"
  2. 2Enable the Street View Publish API
    Click Enable on the API page. It is free.
    Open the API page
  3. 3Set up the consent screen
    • Get started: any app name, your email as support and contact address
    • Audience: External
    • Then under Audience → Test users add your own Google address
    Open consent screen
  4. 4Create the OAuth client
    Application type Desktop app, any name, Create. Keep the dialog with the Client ID and Client Secret open, or click Download JSON.
    Open "Create OAuth client"

    Copy both values into the fields below, or choose the downloaded client_secret_….json, which fills both.

Google Place ID optional

What is a Place ID and where do I get it?

A Place ID ties your photos to a place on Google Maps (a shop, a museum, a square), so they also appear on that place's page. It is optional – without it the photos are still published at their position.

  1. Open Google's Place ID Finder (free, no key or account needed).
  2. Type the name or address of the place into the search box on the map and pick it from the list.
  3. Copy the Place ID shown in the info box – it usually starts with ChIJ – and paste it above.

Not every address has a Place ID that Google accepts for Street View photos. If Google rejects it, the photos are uploaded without it and you are told.
