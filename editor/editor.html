The blurred photo replaces the original in this project (Ctrl+Z undoes it). Its EXIF block, which can hold an unblurred thumbnail, is dropped; the 360° (XMP) metadata is kept. The Street View Publish API does not blur anything itself, so do this before uploading.

How to Use
  1. Drop photos onto the map, or double-click empty map area to add a point
  2. If GPS exists, photos are placed automatically; otherwise they are placed at the drop point
  3. Click a node to select it — a quick-action ring pops up for start / connect / duplicate / delete
  4. Right-click a node, then right-click a second node to connect them (right-click again to cancel)
  5. Type exact coordinates, adjust heading, and use the compare view on the selected node
  6. Walk to linked nodes inside the same file while checking the result
Power tools
  1. Press Ctrl K for the command palette, ? for all shortcuts
  2. Ctrl/Shift-click nodes to multi-select, then bulk-connect or delete
  3. Everything autosaves — closing the tab is safe, a restore prompt appears next time
  4. Save the whole project with photos as a .vrtour file; open it again or drop it on the map

Upload to Google Street View Close

One-time setup, about 5 minutes: Google needs you to register this app as your own free "OAuth client". Work through the steps, each link opens the right page of Google Cloud Console.
  1. 1Create a Google Cloud project
    Sign in with the Google account that should own the photos, give the project any name (e.g. Street View Upload) and click Create. Make sure it is selected in the project picker at the top afterwards.
    Open "New project"
  2. 2Enable the Street View Publish API
    Click Enable on the API page. It is free.
    Open the API page
  3. 3Set up the consent screen
    • Get started: any app name, your email as support and contact address
    • Audience: External
    • Then under Audience → Test users add your own Google address
    Open consent screen
  4. 4Create the OAuth client
    Application type Desktop app, any name, Create. Keep the dialog with the Client ID and Client Secret open, or click Download JSON.
    Open "Create OAuth client"
  5. 5Paste the two values here
    Copy both values into the fields below, or choose the downloaded client_secret_….json, which fills both.
