Places on Google Maps recommended Close

Optional, but recommended: with an API key of your own, the editor ties every photo to its place on Google Maps – the building or business it was taken at, its house number or its street – so it also appears there. Before anything is uploaded you see which place each photo gets and why, and can change it. Without a key, photos are published at their position, as before.
  1. 1Turn on two APIs
    In the Google Cloud project you use for the upload, enable Places API (New) (buildings and businesses) and Geocoding API (house numbers and streets).
    Places API (New)Geocoding API
  2. 2Set up billing
    Google requires a billing account for these APIs, even for their free monthly usage. Free each month (2026): 10,000 address lookups and 5,000 place searches; above that Google charges (about $5 and $32 per 1,000). The editor looks up each photo once – a second time only if you move it – and searches for buildings only for tours that lie at one place.
    Open billingGoogle's prices
  3. 3Create a key
    Create credentials → API key. Then open the key and, under API restrictions, allow only Places API (New) and Geocoding API.
    Open credentials
  4. 4Set a daily limit (recommended)
    So that it can never cost anything: on each API's Quotas page, set the requests per day to 300 (Geocoding API) and 150 (Places API, Nearby Search). Then Google stops at the free usage instead of charging, and the editor uploads those photos with their position only.
    Geocoding quotasPlaces quotas
  5. 5Paste the key
The key is stored on this computer only, next to your Google sign-in. Only the positions of the photos you are about to upload are sent to Google's Places and Geocoding APIs, when you open the upload.

What is a Place ID and where do I get it?

A Place ID ties your photos to a place on Google Maps (a shop, a museum, a square), so they also appear on that place's page. It is optional – without it the photos are still published at their position.

  1. Open Google's Place ID Finder (free, no key or account needed).
  2. Type the name or address of the place into the search box on the map and pick it from the list.
  3. Copy the Place ID shown in the info box – it usually starts with ChIJ – and paste it above.

Not every address has a Place ID that Google accepts for Street View photos. If Google rejects it, the photos are uploaded without it and you are told.

Faces and licence plates in all photos Close

Looks for faces and vehicles in every photo - on this computer, nothing is sent anywhere. Then go through the photos with findings: each opens in the blur tool with the suggestions marked, for you to check and apply. Plate suggestions are the lower middle of each vehicle, where plates usually are.

360° video to Street View Close

Google turns a 360° video into Street View photos itself: it picks the frames, places them along the GPS track and links them. It needs a 360° video (MP4, 2:1, as the camera's app exports it) recorded while walking or driving outdoors, and GPS for all of it - in the video's motion track (CAMM) or as a GPX file recorded at the same time. Processing at Google takes hours to days. The video does not become part of this tour.

Create a bug report Close

A bug report helps to find out what went wrong. It is a zip file with the versions of the app and of your system, the app's log and the editor's last messages and errors (they can contain the names of your points). It holds no photos, no projects, no Google sign-in and no keys - whatever in the log looks like a key or a token is blanked. Have a look inside before you send it.

North from the photos Close

Compares each photo's horizon with its linked neighbours: once one photo faces north correctly, the others are turned to match it - whichever way you held the camera. Works best with photos a few metres apart. Every result shows how sure it is; only clear ones are ticked.
