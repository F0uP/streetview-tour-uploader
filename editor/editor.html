How to Use
  1. Drop photos onto the map, or double-click empty map area to add a point
  2. If GPS exists, photos are placed automatically; otherwise they are placed at the drop point
  3. Click a node to select it — a quick-action ring pops up for start / connect / duplicate / delete
  4. Right-click a node, then right-click a second node to connect them (right-click again to cancel)
  5. Type exact coordinates, adjust heading, and use the compare view on the selected node
  6. Walk to linked nodes inside the same file while checking the result
Power tools
  1. Press Ctrl K for the command palette, ? for all shortcuts
  2. Ctrl/Shift-click nodes to multi-select, then bulk-connect or delete
  3. Everything autosaves — closing the tab is safe, a restore prompt appears next time

How do I get a Client ID / Client Secret?
  1. Open Google Cloud Console and create (or pick) a project
  2. APIs & Services → Library → search Street View Publish API → Enable
  3. APIs & Services → OAuth consent screen → External → add your own email under Test users
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID → type Desktop app
  5. Copy the Client ID and Client Secret shown and paste them below (pasting the whole downloaded JSON into the Client ID field also works)
